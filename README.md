# Stock Manager App

A simple React Native app for managing stock items which was created as part of coding pactice. The app allows users to view, create, and manage stock items.

## Getting Started

Before running the app, make sure your React Native environment is set up correctly.

### 1. Install dependencies

```bash
npm install
```

### 2. Start Metro

```bash
npm start
```

### 3. Run the app

#### Android

```bash
npm run android
```

#### iOS

If you are running on macOS, install CocoaPods first if needed:

```bash
cd ios
pod install
cd ..
```

Then run:

```bash
npm run ios
```

## Project Structure

## Notes

- This project uses React Native with Expo-style project structure.
- For Android/iOS development, use a simulator or connected device.
- If the app is not updating, restart Metro or reload the app.
